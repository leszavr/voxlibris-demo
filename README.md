# VoxLibris Demo

Портативная демонстрационная среда платформы **VoxLibris** — клубы, книжные
сессии, аудио-эфиры VoxLibris Studio, чат и платежи.

Разворачивается одним файлом, работает локально (`127.0.0.1`), **не требует прав
администратора** и ничего не устанавливает в систему. Docker не нужен.

## Скачать

Готовые сборки — в разделе [**Releases**](../../releases/latest):

| Платформа | Файл | Размер |
|---|---|---|
| Windows 10/11 (x64) | `Voxlibris-Demo-Setup.exe` | ~341 МБ |
| Linux (x64) | `Voxlibris-Demo-Linux` | ~352 МБ |

Контрольные суммы — `SHA256SUMS.txt` в релизе.

## Быстрый старт

1. Скачайте файл для своей платформы.
2. Запустите его (Windows: двойной клик).
3. Дождитесь сообщения **«ГОТОВО — демо-среда VoxLibris запущена»**.
   Откроются приложение, справка и лицензия.
4. Войдите под нужной ролью.

| Роль | Логин | Пароль |
|---|---|---|
| Администратор (полный доступ) | `admin@voxlibris.test` | `Admin123!` |
| Чтец | `reader@voxlibris.test` | `Reader123!` |
| Слушатель | `listener@voxlibris.test` | `Listener123!` |
| Участник | `member@voxlibris.test` | `Member123!` |

## Что можно проверить

- создание клубов, книг, сессий чтения и расписания;
- чтение книг (демо-книги с главами);
- запуск стрима Studio через Icecast и подключение слушателей;
- чат клуба (Socket.IO) — сообщения, история, участники;
- платежи через **эмулятор ЮKassa** (подписки и тарифы клуба чтецов);
- гостевой доступ, лента, личные сообщения, геймификация, админка.

## Как это устроено

Всё живёт в одной папке `%USERPROFILE%\.voxlibris-demo` (Linux: `~/.voxlibris-demo`):

- портативный **PostgreSQL** (данные внутри папки, без системной службы);
- **SeaweedFS** — S3-совместимое хранилище;
- **Icecast** + **ffmpeg** — стриминг;
- портативный **Node.js** — сервер VoxLibris и эмулятор ЮKassa.

Порты по умолчанию (высокий блок, не конфликтует с системными службами):

| Сервис | Порт |
|---|---|
| VoxLibris | 45800 |
| PostgreSQL | 45801 |
| S3 (SeaweedFS) | 45802 |
| Icecast | 45803 |
| Эмулятор ЮKassa | 45804 |

Если блок занят, установщик подберёт свободный. Базовый порт можно задать явно:
```powershell
$env:VOXLIBRIS_PORT=51000; .\Voxlibris-Demo-Setup.exe
```

## Управление

Значок **«VoxLibris Demo»** в трее (Windows 11 — возможно, в меню `^`):

- Открыть VoxLibris · Справка · Лицензия;
- Запустить / Остановить / Перезапустить;
- Статус (логи) · Открыть папку среды;
- **Полная деинсталляция** (остановка служб и удаление файлов среды).

Те же команды из строки:
```
Voxlibris-Demo-Setup.exe start | stop | restart | status | uninstall
```

## Удаление

Полная деинсталляция = остановка процессов и удаление папки среды. Система,
реестр и другие приложения не затрагиваются — среда портативная.

## Требования
